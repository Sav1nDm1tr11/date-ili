# ИЛИ — ужин без правок

Личное приглашение на ужин. HTML/CSS/JavaScript без сборки и зависимостей.

## Запуск

Из этой папки: `python3 -m http.server 4173`. Открыть http://localhost:4173.

Тесты: `node --test tests/*.test.mjs` (Node.js 22+).

## Поведение

«Да» открывает три шага: дата/время, несколько планов, свой вариант и пожелания, готовое сообщение. Ссылка открывает чат с Sav1nDm1tr11 с черновиком; посетитель сам нажимает «Отправить» в Telegram. Есть копирование с ручным запасным вариантом. Данные формы остаются в памяти страницы и не отправляются на сервер.

Кнопка «нет» убегает бесконечно в одну из шести случайных позиций внутри своего блока, не повторяя предыдущую позицию и избегая указателя; шесть реплик повторяются по кругу. Поддержаны касания. Клавиатура и настройка reduced motion отключают побег. Отдельная ссылка позволяет отказаться сразу. Отказ показывается локально, сообщение о нём не отправляется.

## Редактирование

- `index.html`: тексты и структура.
- `style.css`: оформление и адаптивность. Заголовки — Unbounded Bold, текст — Inter.
- `logic.js`: получатель Telegram, адрес, формирование сообщения и проверка дат.
- `app.js`: форма, диалог, бесконечный побег и уведомления.

Дата/время интерпретируются в локальном часовом поясе посетителя и так подписаны в сообщении. Бронирование ресторана не выполняется.

## Проверено

- Шесть тестов логики: некорректные/прошедшие даты, Unicode и кодирование сообщения, 100 позиций побега на трёх ширинах.
- Реальный браузер: форма, обязательная дата, сохранение ответов при возврате, копирование, правильный получатель ссылки Telegram, отказ с клавиатуры.
- Мобильная вёрстка без горизонтальной прокрутки при фактической ширине 320px.
- Нет ошибок и предупреждений в консоли при проверенных сценариях.

Фактическая отправка в Telegram не выполнялась: действие оставлено посетителю. Телефоны и разные приложения Telegram отдельно не проверялись.
